# Help Soluções — site de demonstração

Site estático sem dependências de build, convertido de `Help Site.dc.html`.

## Prévia local

No diretório do projeto: `python -m http.server 8000` e abra `http://localhost:8000`.

## Deploy na Vercel

Framework **Other** / No Framework, Output Directory vazio, sem build. Deploy Preview (não produção). Não exige compra de domínio.

## Observações

- O formulário valida os campos no navegador, mas **não envia ou armazena dados**.
- Política de Privacidade provisória. Revisar antes do uso público real.
- Nome/identidade visual, escopo de serviços e meios de contato dependem de aprovação do Marcus.
- Nenhuma integração com Milldesk, WhatsApp ou banco de dados.
- `robots.txt` e `noindex` evitam indexação da prévia.
